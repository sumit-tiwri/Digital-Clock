# ⚡ Neon Cyber Clock

A sleek, modern desktop digital clock application built entirely in Python using `tkinter`. Features a dark-mode cyberpunk aesthetic, clean typography, and a dynamic circular progress ring that fills up in real-time with every passing second.

---

## ✨ Features

* **Dynamic Seconds Ring**: Smooth circular arc on a canvas that tracks seconds in real-time ($0^{\circ}$ to $360^{\circ}$).
* **Cyberpunk UI**: Minimalist midnight theme with electric cyan (`#00F0FF`) and crimson (`#F43F5E`) accent lighting.
* **Full Date & Time Display**: Displays 12-hour time format with AM/PM indicators, current day, and formatted date.
* **Zero External Dependencies**: Built strictly using Python's standard library—no `pip install` required!

---

## 🛠️ Built With

* **Python 3.x**
* **Tkinter** (GUI Framework)
* **Time Module** (System time fetching)
